# 📝 To-Do List Web App

This is a simple To-Do List web application built using HTML, CSS, and JavaScript.

## 🚀 Features
- Add tasks
- Delete tasks
- Mark tasks as completed
- Prevent empty inputs

## 🛠️ Tech Used
- HTML
- CSS
- JavaScript

## 📌 What I Learned
- DOM manipulation
- Event handling
- Debugging JavaScript
- Improving UI structure
